# 5. Maze Chase

## What is the challenge?
Build an original browser-based maze chase game inspired by classic Pac-Man mechanics, with original visuals, level design and naming.

## Input available
Public descriptions of maze-chase mechanics and enemy behaviour. No original game assets or proprietary source code are supplied.

## What should we see tomorrow?
A playable polished browser game with movement, scoring, collectables, power-ups, multiple enemy behaviours, level completion and clear visual feedback.

## Acceptance test
The full game loop must work, enemy movement must be consistent, collisions/scoring must behave correctly, and the game must use original assets and layout.
